# Proč roste důstojná mzda

Odhad minimální důstojné mzdy (MDM) pro rok 2026 a web s rámcem šok / renta / přesun.

- `vypocet.py`: výpočet. Vstupem je koš Platformy MDM za rok 2025 a změny cen podle ČSÚ z října 2026. Výstup se uloží do `data.json`.
- `index.html`: statický web. Data jsou do něj vložená, takže funguje bez serveru.

Jde o orientační odhad, ne o oficiální hodnotu Platformy. Předpoklady jsou popsané ve skriptu.
